## 🌟 Overview & Features

- **15 Integrated Sections & 9 Routed Pages**:
  - **Home**: Hero carousel, quick appointment & procedure selector, trust pillars, treatment showcases, verified before/after results, transparent pricing, and patient reviews.
  - **About Us**: Clinical philosophy, sterilization standards, and doctor credentials.
  - **Treatments Directory**: Detailed procedural information, duration, anesthesia, and recovery guidelines.
  - **Before & After Gallery**: Interactive touch/mouse comparison sliders across 9 verified clinical cases.
  - **Specialists**: Detailed profile for Dr. LABABOU.N with direct appointment booking.
  - **Pricing**: Transparent fee schedule with material passports and warranty coverage.
  - **Direct Booking**: Instant consultation form with pre-filled WhatsApp integration.
  - **Contact & Location**: Address, working hours, and direct clinic telephone hotline.

- **Theme Engine**:
  - Full **Dark Mode** & **Light Mode** support with smooth color transitions and persistent user preference.

- **Technology Stack**:
  - **React 19** + **Vite 8**
  - **Tailwind CSS v4** (`@theme` tokens & custom variants)
  - **React Router DOM v7**
  - **React Icons** (`react-icons/lu`, `react-icons/fa`)

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

### 3. Lint & Audit
```bash
npm run lint
```

### 4. Build for Production
```bash
npm run build
```
